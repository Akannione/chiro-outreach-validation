# Local Data

CSV files in this folder are generated locally and intentionally ignored by git.

They may contain clinic names, public emails, outreach status, replies, opt-outs, and survey data. Do not commit them to GitHub.

Expected generated files:

- `contacts.csv`
- `outreach_log.csv`
- `suppression_list.csv`
- `manual_responses.csv`
- `form_responses.csv`
